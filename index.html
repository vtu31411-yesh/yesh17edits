why does this look like a video game — dev notes

Short version: we didn't have a real drone, a backend, or a Google Maps API key by the time we sat down to build this, so everything here — the drone, the traffic, the "AI" — runs in your browser as one big simulation. The route math (graph search + cost ranking) is real code that actually runs, not a fake animation; the drone footage and live traffic feed are not. Full breakdown of what's real vs. simulated is in our project report. We built this over one very long weekend, so if something looks slightly held together with tape, it's because it is.

AEROUTE — built by Team AEROUTE for Smart India Hackathon 2026 (SIH26201). Prototype / research simulation, not certified for real-world emergency dispatch.
